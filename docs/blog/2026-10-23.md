# Journal du 23 octobre 2026

## Changement d'ordre : le calcul de profil passe avant les mires

Le FD-9 est mesuré chaque jour avec FD-S2w, et son export CGATS contient déjà tout ce qu'il faut : les valeurs RVB imprimées, les Lab et les spectres. Calculer le profil à partir de cet export rend « Refaire le profil » utile tout de suite, sans attendre les mires de myiro-libre (#33) ni la mesure d'une feuille au FD-9 (#34). La feuille de route du [plan du 23 octobre](../superpowers/plans/2026-10-23-profil-rvb-import-fd-s2w.md) le dit.

## Calculer un profil RVB depuis une mesure importée

Ticket [#40](https://github.com/entropik/myiro-libre/issues/40), première partie, sur l'[ADR 0002](../adr/0002-argyllcms-inclus.md) (ArgyllCMS inclus).

Dans la vue d'une résolution, une nouvelle section « Calculer un profil » :

- **On choisit la mesure** importée depuis un export FD-S2w, puis la **condition de mesure** (M1 par défaut). Seules les conditions présentes dans le fichier sont proposées. Si une mesure ne peut pas servir (pas de valeurs RVB, par exemple une mesure ponctuelle), le bouton reste inactif et la raison est écrite juste à côté.
- **On choisit la recette de calcul** : Rapide pour un essai, Standard pour la production (par défaut), Approfondi pour le plus fin. Les trois ajoutent une table perceptuelle pensée pour les fichiers RVB envoyés par le pilote.
- **« Avancé : commande équivalente »** montre, avant le calcul, la commande exacte qu'ArgyllCMS va recevoir, en lecture seule.
- Pendant le calcul, la page dit qu'il est en cours et qu'il peut durer plusieurs minutes.
- À la fin, le profil devient le **profil actuel** de la résolution, sous un nom lisible, avec sa **précision du calcul** : l'écart ΔE00 moyen et maximal entre les mesures et ce que le profil prédit. Il est marqué **« non vérifié »** : un calcul réussi ne dit pas encore que le profil est bon, c'est la vérification sur une seconde mire qui le dira.
- La recette, la version d'ArgyllCMS, la commande et le journal du calcul sont gardés avec le profil, dans « Avancé : commande et journal ».
- En cas d'échec, on lit l'étape, le message d'ArgyllCMS et quoi faire. L'ancien profil reste actif, rien n'est rangé à moitié, et les fichiers de travail sont effacés.

Ce qui n'est pas dans le fichier reste inconnu : l'échelle des valeurs RVB d'un export FD-S2w (0 à 255) est **supposée**, d'après les exports du poste, et dite telle ; pour un fichier d'origine inconnue, le calcul est refusé plutôt que deviné.

## ArgyllCMS 3.5.0, et rien d'autre

- Le calcul est fait par ArgyllCMS, un logiciel libre de profilage, dans la seule version **3.5.0**. Une autre version est refusée avec un message clair : changer de version sera une décision à part, testée sur des mesures de référence.
- S'il manque, l'application le dit et indique où le placer (dossier `argyll` à côté de l'application). La vue reste utilisable.
- **L'installateur** embarque ArgyllCMS 3.5.0 quand le dossier `argyll/` est posé à la racine du dépôt : `colprof`, `profcheck`, le profil sRGB de référence et le texte de la licence. Sans ce dossier, l'installateur se fait quand même, sans ArgyllCMS, et le script le signale en une ligne.
- **Licence** : ArgyllCMS est sous AGPL-3.0. Chaque fois qu'un installateur qui le contient est publié, il faut fournir à côté les sources d'ArgyllCMS 3.5.0, ou leur lien précis.

## Essai d'écran

**Fait le 26 octobre** pour l'essence : une vraie mesure (FD-9 en M1, 2 520 plages) importée dans « Canon PRO-4100 / HFA Mat 200g », calcul en Standard en un peu moins de 3 minutes, précision 0,22 ΔE00 en moyenne et 3,53 au maximum ; voir le [journal du 26 octobre](2026-10-26.md). Restent de ce qui était prévu (capitaine et mainteneur) : les recettes Rapide et Approfondi, l'installation dans Windows et l'ouverture dans un logiciel de l'atelier, l'essai sans `argyll/`. Prévu à l'origine : importer un vrai export FD-S2w (M1) dans « Canon PRO-4100 / papier / résolution », calculer avec chaque recette, noter la durée, la précision et le nom du profil, installer le profil dans Windows et l'ouvrir dans un logiciel de l'atelier, puis recommencer sans `argyll/` pour voir le message.

## Ce qui reste « Prévu »

- **Durées des recettes** : les textes ne donnent aucune durée (« durée à mesurer à l'essai ») ; les durées mesurées sur le poste à l'essai d'écran les remplaceront. Mise à jour du 26 octobre : Standard mesurée (environ 3 min pour 2 520 plages), voir le [journal du 26](2026-10-26.md).
- **Mire produite par myiro-libre** (#33), **moyenne de plusieurs exemplaires** (#35) et **vérification du profil** avec tolérances (#41) : le profil reste « non vérifié » jusque-là.
- **CMJN** : seul le RVB est calculé pour l'instant.
- Cocher « Installer dans Windows » d'office après un calcul viendra avec le parcours complet en quatre étapes.
