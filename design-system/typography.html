Graisses

Quatre graisses

400 pour le texte, 500 pour les titres et le verdict, 600 pour les libellés, le nœud d’imprimante et le bouton principal, 700 pour la marque.

Quatre cents : texte courant

Cinq cents : titres, verdict

Six cents : libellés, imprimante

Sept cents : marque

Libellés

Capitales, approche large

Uniquement des libellés courts en capitales (jamais de capitales dans le texte courant). Approche de 0,12 em.

Condition de mesure

M1 · D50 · 2°
