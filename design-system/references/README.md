# Références typographiques et rédactionnelles

Les règles détaillées de composition (typographie française, tirets et guillemets, apostrophe, fer à gauche, corps optique, typographie responsive, états de formulaires, animations, impression) sont dans le skill personnel de l'auteur du projet, non versionné. Résumé des règles appliquées : voir `../typography.html` et `../README.md`.

Références publiques de premier rang : le site de Bruno Bernard (Café Typo) pour la typographie française, v-fonts.com et wakamaifondue.com pour les fontes variables, utopia.fyi pour les échelles fluides.
